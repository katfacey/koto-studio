KOTO Studio **0.3.0 Alpha** adds local UVR-style separation and reusable character voices to the Windows/NVIDIA dubbing workflow.

### What's new

- **UVR-style vocal separation:** isolated MDX-Net, VR and BS-RoFormer workers, explicit verified model downloads, source-range previews, aligned Original / Dialogue / Background comparison, saved results and switching full-project stems. Existing Demucs remains available.
- **Reusable character voice library:** saved voices with immutable versions, copied samples and project snapshots. Reuse a character across projects and explicitly adopt newer versions without changing old assignments.
- **Local voice cloning and design:** Qwen3-TTS Base reference cloning, VoiceDesign description-based auditions, and saving a chosen audition as a reusable cloning reference. Existing Piper and XTTS remain available.
- **Individual clip control:** independent voice/reference/seed and supported delivery overrides, retained generated/imported takes, and explicit older-take selection. Compatible lines share loaded models/references while preserving per-line settings.
- **App-owned installation:** new Install-Separation.cmd, Install-Qwen-Voices.cmd and Install-Voice-Design.cmd entry points; private workers and pinned model snapshots stay inside the app folder. A future GUI redesign can reuse the same backend APIs.

The voice-library workflow is **inspired by Voicebox**. Separation uses the same model families associated with **UVR5**, through audio-separator; neither external application needs to be installed. **DramaBox has been evaluated and documented, but is not a built-in working adapter in this release.** Windows/RTX 5090 validation and upstream licensing review remain before that integration.

### Download and install

Download **KOTO-Studio-v0.3.0.zip** below and extract the entire folder. Run **Install.cmd**, choose optional workers through **Install-Models.cmd**, then run **Start.cmd**. This ZIP includes source and the built browser editor; app-owned runtimes and model weights download during setup. It is not a signed Windows executable.

For an existing installation, close KOTO and back up the whole app folder. Copy the ZIP's KOTO-Studio contents into your existing app folder, preserving **data/**, **runtime/**, **.venv/** and **.workers/**. Run **Install.cmd**, install the optional new workers you want, restart, and refresh the editor with **Ctrl+F5**. The earlier 0.2.5 release remains unchanged.

### Validation and alpha limits

The feature baseline passed **48 backend tests**, Windows Chromium editing/library/export checks, real Piper/XTTS/Qwen CPU inference (including VoiceDesign then cloning), and real MDX/VR/BS-RoFormer preview/full-separation API jobs. The release publisher additionally requires the Windows workflow to pass for the exact tagged source snapshot. See [VALIDATION.md](https://github.com/katfacey/koto-studio/blob/v0.3.0/VALIDATION.md) for evidence and limits.

These checks validate integration, installation and timing. RTX 5090 GPU performance, voice similarity and Japanese/Chinese reference quality still require testing and listening on the target machine. No video inpainting, subtitle OCR, automatic lip sync, cloud inference or Pinokio installer is included. Future releases will improve the GUI, processing speed and other quality-of-life features.
